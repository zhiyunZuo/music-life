# MUSIC LIFE · 音乐人生 RPG

一个用**原生 HTML / CSS / JS**（零框架、零构建）做的「音乐学习 + 人生模拟」RPG 小游戏。

> 不是「看课程」，而是「成为一个音乐人」——你在游戏里创建角色、做音乐能力检测、练琴、学和声 / 即兴 / 作曲 / 编曲 / 练耳，进度自动保存在本机。

## 在线体验

部署在 GitHub Pages：

```
https://zhiyunZuo.github.io/music-life/
```

## 功能模块

- **角色创建 / 音乐能力检测**：首次进入做约 3 分钟能力测评（音程、和弦、调式、节奏、乐理），生成你的起点属性。
- **学习 / 教学（知识地图）**：钢琴应用、和声、即兴、作曲、编曲、DAW、配器、练耳、分析、音乐史等方向，知识点全部直接开放，点进去有「知识讲解 → 音乐例 → 如何应用 → 实践 → AI 提问」五段式内容。
- **练耳听辨训练**：参考音乐学院视唱练耳题型——音程、和弦与色彩、调式判断、和弦连接 / 功能听辨，播放音频后四选一作答并附解析。
- **洞穴游戏 / 日常任务**：把练习变成 RPG 玩法。

## 本地运行

纯静态站点，无需构建：

```bash
# 方式一：直接用浏览器打开
open index.html        # macOS
# 或把整个文件夹用任意静态服务器托管

# 方式二：本地起一个静态服务器
python3 -m http.server 8123
# 然后访问 http://127.0.0.1:8123/index.html
```

## 目录结构

```
index.html        # 入口
css/style.css     # 样式
js/
  audio.js        # WebAudio 合成（音程 / 和弦 / 和弦连接 播放）
  data.js         # 课程 / 题库数据
  learn.js        # 学习 / 教学板块、练耳引擎
  arrange.js      # 编曲 / 配器相关
  app.js          # 主程序（角色 / 地图 / 任务 / 洞穴游戏 / 测评）
```

## 技术说明

- 无任何第三方框架与构建步骤，双击 `index.html` 即可运行。
- 音频用 Web Audio API 实时合成，无需音频素材文件。
- 存档使用浏览器 `localStorage`。

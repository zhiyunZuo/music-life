# MUSIC LIFE · 音乐人生 RPG

> 你不是来"看课程"的，你是来过一段音乐人生的。
>
> 从第一次认全指板上的音，到听出和弦里那个藏着的变化音，再到在 DAW 里导出属于自己的第一首曲子——
> 中间要经过和声、即兴、编曲、练耳，还要在三百年的音乐史里，遇见那些真实活过的人。

一个用**原生 HTML / CSS / JavaScript**（零框架、零构建、零依赖）写的音乐学习 RPG。打开就玩，进度自动存在你的浏览器里。

## 你会在这里做什么

### 乐器库 · 12 件乐器，每件都是一整套体系

钢琴、吉他、小提琴、大提琴、竖琴、笙、箫、长笛、木琴、马林巴、手碟、声乐。

不是"换个名字同一个模板"——每件乐器都按自己的逻辑重写：吉他的 CAGED 与推弦音准、小提琴的运弓接触点、笙的吹吸自由簧与多声部和音、马林巴的四槌握法、长笛的波姆系统与吐音、手碟的固定音阶与止音……

每件乐器三个入口：**课程**（分入门 / 进阶 / 高级 / 大师课）、**知识库**（14 项：历史、结构、声学、音域、音色、技术、技巧、曲目、风格、合奏、写作、改编、制作、来源）、**图解**（矢量讲解图）。

其中最有意思的是**大师课**：演奏家视角拆解同一句旋律——换个触键、换个运弓接触点、改一点口风，声音就完全不是一回事。

### 音乐历史长河 · 遇见真实的他们

七个时期，四十位音乐家的档案，十二件改写音乐史的大事，还有五条乐器发展的线索（比如钢琴是怎么从古钢琴一步步变成今天的样子）。

首页每天会给你推一位——**「今天遇见谁」**。今天可能是巴赫，明天可能是德彪西。

### 音乐实践中心 · 练完留下痕迹

八个方向：今日练习、练耳、乐器练习、和声与理论、即兴、编曲与配器、DAW 与制作、分析与聆听。

每个训练项都写清楚了**怎么做、怎么算做对、建议练多久**。可以计时、记录正确数，系统会把你的薄弱点攒成一份 Top 5 摆在页面顶部——不是"点亮一个图标"就算过了，而是真的知道自己哪儿不行。练耳部分能直接在线听音程答题并自动判分。

### 音乐世界 · 十二个可探索的地方

古典之城、和声森林、练耳洞穴、制作人街区、吉他街、管弦厅、东方音乐村、演出舞台、影视音乐工作室、游戏音乐实验室、爵士俱乐部、实验实验室。

每个区域都有自己的知识线、作品和可播放的例子。

### 知识森林 · 五条成长路线

钢琴应用、和声、即兴、伴奏、作曲、编曲、DAW / 制作、管弦配器、视唱练耳——五条分支、四十三个节点。风格横跨古典、爵士、流行、影视游戏音乐与中国传统音乐。

所有知识点**直接可学**，没有解锁、没有等级门槛、没有前置课程。

### 工作室 · 十二步做出第一首曲子

从"DAW 到底是什么"开始，一路走到"导出、备份、放进作品集"：选工作站、装软件、设置音频设备解决延迟、连 MIDI 键盘、建第一条轨、加载音色、录四小节旋律、加鼓、加贝斯、加和弦。每一步都告诉你为什么要做、怎么做、以及新手最容易踩的坑。

### TODAY'S QUEST · 今天练什么

三步问卷（乐器 / 目标 / 有多少时间），生成一份当天就能照着做的清单。

## 本地运行

纯静态站点，不需要构建，也不需要 npm install：

```bash
python -m http.server 8123 --bind 127.0.0.1
# 然后访问 http://127.0.0.1:8123/index.html
```

直接双击 `index.html` 也能跑，但部分浏览器对本地文件有限制，推荐用上面的方式。

## 技术说明

- **零框架、零构建、零第三方依赖**：只有 HTML / CSS / 原生 JS，改完刷新即可。
- **音频实时合成**：Web Audio API 现场合成音高、和弦、音阶与节奏，不依赖任何音频素材文件。
- **图解全部矢量渲染**：五线谱、和弦堆叠、指板、频谱、信号链这类需要精确定位的图用 SVG 程序化绘制，可复用、可测试、放大不失真。
- **存档在 localStorage**：不上传任何数据，无后端、无账号。

## 写作原则

- 每个知识点都包含：通俗讲解 + 专业讲解 + 真实作品例（曲名 + 作者 + 具体用法）+ 可照做的步骤 + 具体实践任务。
- **不编造**：年份、作品号、名言不确定的，一律标注"具体年代难以确证""命名存在争议""待权威资料补充"。
- 传说与起源（如笙与"匏"、手碟与钢鼓的关系）标注为文献记载或学界推测，不写成确证事实。
- 禁止"暂无内容 / 敬请期待"这类占位文案。
- 声乐部分只给常识性护嗓原则，不给医疗诊断建议。

## 开发自检

```bash
node --check js/*.js     # 语法检查
node _smoke.js           # 冒烟测试（虚构 DOM + vm 沙箱）
```

冒烟测试会校验：模块是否正常挂载、乐器知识库 14 项是否齐全、节点字段长度是否达标、所有 SVG 图解渲染后是否出现 `NaN` / `undefined` 或坐标越界。

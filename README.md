# MUSIC LIFE · 音乐人生 RPG

一个用**原生 HTML / CSS / JavaScript**（零框架、零构建、零依赖）写的「音乐学习 + 人生模拟」RPG。

> 不是"看课程"，而是"成为一个音乐人"——练琴、学和声 / 即兴 / 编曲 / 练耳、探索音乐史、在 DAW 里做出第一首曲子，进度全部自动保存在本机浏览器里。

## 功能模块

### 1. 乐器库（12 件，每件都是独立体系）
每件乐器都有三个标签页：**课程**（分级知识节点）、**知识库**（14 项）、**图解**（矢量讲解图）。

| 乐器 | 节点 | 乐器 | 节点 |
|---|---|---|---|
| 钢琴 | 23 | 笙 | 27 |
| 吉他 | 30 | 箫 | 24 |
| 小提琴 | 23 | 长笛 | 26 |
| 大提琴 | 28 | 木琴 | 23 |
| 竖琴 | 23 | 马林巴 | 26 |
| 声乐 | 28 | 手碟 | 23 |

每件乐器的 14 项知识库：历史 · 结构 · 声学 · 音域 · 音色 · 技术 · 技巧 · 曲目 · 风格 · 合奏 · 写作 · 改编 · 制作 · 资料来源。

每个知识节点统一为四段：**讲解 → 音乐例 → 如何运用 → 实践任务**，并配 SVG 图解。其中每件乐器含 4–5 节**大师课**（演奏家视角：同一句旋律如何靠触键 / 运弓 / 口风 / 槌头 / 气息改变声音）。

### 2. 音乐历史长河
7 个时期（中世纪 → 当代）、40 位真实音乐家档案、12 件音乐史大事、5 条乐器发展线（如钢琴、小提琴家族的形制演变）。首页有**「今天遇见谁」**——按日期轮换一位音乐家。

### 3. 音乐实践中心
今日练习 / 练耳 / 乐器练习 / 和声与理论 / 即兴 / 编曲与配器 / DAW 与制作 / 分析与聆听。
每项训练含「怎么做 + 自检标准 + 建议时长」，可计时、记录正确数，顶部汇总周统计与**薄弱点 Top 5**。练耳模块支持在线音程答题并自动判分。

### 4. 学习 / 知识森林
5 条技能分支、43 个节点，覆盖钢琴应用、和声、即兴、伴奏、作曲、编曲、DAW / 制作、管弦配器、视唱练耳，风格横跨古典、爵士、流行、影视 / 游戏与中国传统音乐。

### 5. 音乐世界
12 个区域：古典之城、和声森林、练耳洞穴、制作人街区、吉他街、管弦厅、东方音乐村、演出舞台、影视音乐工作室、游戏音乐实验室、爵士俱乐部、实验实验室。

### 6. 工作室
12 步把一首曲子真正做出来：认识 DAW → 选工作站 → 装软件 → 设置音频设备 → 连 MIDI 键盘 → 建第一条 MIDI 轨 → 加载音色 → 录四小节旋律 → 加鼓 → 加贝斯 → 加和弦 → 导出备份。

### 7. TODAY'S QUEST
三步问卷（乐器 / 目标 / 时间）生成当日 3–6 条可执行的练习清单。

## 技术说明

- **零框架、零构建、零第三方依赖**：只有 HTML / CSS / 原生 JS，改完刷新即可。
- **音频实时合成**：Web Audio API 合成音高、和弦、音阶与节奏，不依赖任何音频素材文件。
- **图解全部矢量渲染**：五线谱、和弦堆叠、指板、频谱、信号链这类需要精确定位的图用 SVG 程序化渲染，可复用、可测试、不失真。
- **存档在浏览器 localStorage**：不上传任何数据，无后端、无账号。

## 内容与写作原则

- 所有知识节点包含：通俗讲解 + 专业讲解 + 真实作品例（曲名 + 作者 + 具体用法）+ 可照做的步骤 + 具体实践任务。
- **不编造**：年份、作品号、名言不确定的一律标注"具体年代难以确证""命名存在争议""待权威资料补充"，不写传闻。
- 传说与起源（如笙与"匏"、手碟与钢鼓的关系）标注为文献记载或学界推测，不作确证事实陈述。
- 无解锁、无等级门槛，所有知识点直接可学。
- 禁止"暂无内容 / 敬请期待"占位文案。
- 声乐部分只给常识性护嗓原则，不给医疗诊断建议。

## 开发自检

```bash
node --check js/*.js              # 语法检查
node _smoke.js                    # 冒烟测试（虚构 DOM + vm 沙箱）
```

`_smoke.js` 会校验：各模块是否正常挂载、乐器知识库 14 项是否齐全、节点字段长度是否达标、所有 SVG 图解渲染后是否出现 `NaN` / `undefined` 或坐标越界。
